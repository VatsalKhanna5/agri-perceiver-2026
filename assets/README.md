# assets/

Place `banner.png` in this directory. The banner is referenced in the root README.md as:

```html
<img src="assets/banner.png" alt="AgriPerceiver" style="border-radius: 14px; width: 100%; max-width: 960px;" />
```

**Recommended dimensions:** 1280 × 320 px (4:1 aspect ratio), PNG.  
The inline `border-radius: 14px` handles the rounded corners — no need to bake rounding into the image itself.
